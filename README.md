# Switchyard

Switchyard is an original 2D fighting game prototype with ground chains, air juggles, and meter cancels.

Open `index.html` in a desktop browser. Practice mode starts you next to a stationary dummy. Use **Switch to local versus** for a two-player match on one keyboard.

| Action | Player 1 | Player 2 |
| --- | --- | --- |
| Move | A / D | Left / Right |
| Jump | W | Up |
| Guard | S | Down |
| Light | F | I |
| Heavy | G | O |
| Launcher | H | P |
| Meter cancel | J | [ |

Try **light → heavy → launcher → air light → air heavy**. Press each input as the previous strike connects. The launcher sends both fighters airborne. After a hit, spend 50 meter to end your current move early and start a new chain. Consecutive hits deal progressively less damage.
